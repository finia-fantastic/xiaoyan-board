## 四、怎么跑

```bash
pip install playwright
python render_board.py board05_zhanban.html out.png
```

脚本会：开 Edge 无头 → 加载 HTML → 量内容高度 → 等比缩放到正好 3508×4961 → 截图。
**加内容不会溢出**，缩放是自动的。

导出 JPG（带 300dpi 标记）：

```python
from PIL import Image
Image.open("out.png").convert("RGB").save("out.jpg", "JPEG", quality=92, dpi=(300,300), optimize=True)
```

## 五、设计语言（别改掉的三件事）

**① 中文全部由 HTML 排版，不让模型画字**
模型写汉字会缺笔画、字距失控。所有文字都是真实文本。

**② 叠加，不是网格**
每张图带自己的旋转角（-3.2° / 2.6° / 4.4° 之类），互相压角，压在
半透明 HUD 板上（`.hudpanel`），再盖一层全幅扫描线（`.scanlines`）。
**对齐成网格就没有那个味道了。**

**③ 破框**
主视觉出血到画布外（`right:-300px`），标题压在图上，小图压标题。

参考方向：《明日方舟》的界面美学——细线分栏、直角括号、斜切面板、技术小字
（`FIG. 01` `PANEL 02/04`）、大面积负空间、朱红只做点缀。

## 八、排版方法（从社区案例总结的，可直接套）

来自小红书一篇 4567 赞的《米兰设计周「作品排版方法」解析》：

1. **学会梳理**——一张板放什么要分主次：
   展板1 = 作品介绍/灵感来源/设计调研；展板2 = 设计呈现/亮点/效果；展板3 = 延展
2. **建立布局**——每板**一个视觉重心**，重心那份用色块高亮（这里用朱红）
3. **美化细节**——统一色块、大标题小标题分级、字体字号间距要有对比
4. **30 秒电梯法则**——评委 30 秒看不懂就会 PASS。讲清、重点、直接

## 十一、配套工具（生成图用）

**Hoswing MCP** — https://github.com/finia-fantastic/hoswing-mcp
图生图、文生图都能跑，本项目里 `gen/h1~h3`、`gen/g4_detail` 就是它出的。
推荐配置：`relay-485140b2-284c-45de-b440-c4d767be8d1c` + `tencent-vod:OG:image2.5_flare_medium`，一张约 5 积分。
⚠️ 它的「参考视频」链路是坏的（三个模型全报 `PROVIDER_SEEDANCE_RELAY`），只能图 + 提示词。

**烽途 MCP** — https://github.com/finia-fantastic/fengtu-mcp
两段式：先出文字方案（2 积分）→ 满意了再出图（标准 65 / 高级 80）。
⚠️ **未端到端验证**：未登录过、未提交过付费任务，写接口是按网站前端实现反推的，不是官方 API。

两个都要复用本机的 Edge 调试端口（Hoswing 用 9333，烽途也用 9333，别同时开）。
