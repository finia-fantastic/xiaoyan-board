## 这是什么

一个仓库装三样东西：


## 三、怎么跑

```bash
cd board
pip install playwright
python render_board.py board05_zhanban.html out.png
```

脚本会：开 Edge 无头 → 加载 HTML → 量内容高度 → 等比缩放到正好 A3 → 截图。
**加内容不会溢出**，缩放自动。

机器上没有 Python 3.8+、`pip install playwright` 装不上时，用等价的 Node 版
（同样调用本机 Edge，不用下载 Chromium）：

```bash
cd board
npm i playwright-core
node render_board.mjs board05_zhanban.html out.png
```

导出 JPG（带 300dpi）：

```python
from PIL import Image
Image.open("out.png").convert("RGB").save("out.jpg", "JPEG", quality=92, dpi=(300,300), optimize=True)
```

## 四、设计语言（别改掉的三件事）

**① 中文由 HTML 排版，不让模型画**
模型写汉字会缺笔画、字距失控。这里的字全是真实文本。

**② 叠加，不是网格**
每张图带自己的旋转角（-3.2° / 2.6° / 4.4°…），互相压角，垫在半透明 HUD 板上
（`.hudpanel`），再盖全幅扫描线（`.scanlines`）。**改回对齐就废了。**

**③ 破框**
主视觉出血到画布外（`right:-300px`），标题压在图上，小图压标题。

参考方向：《明日方舟》界面——细线分栏、直角括号、斜切面板、技术小字
（`FIG. 01` `PANEL 02/04`）、大面积负空间、朱红只做点缀。

## 七、排版方法（社区案例总结，可直接套）

来自小红书一篇 4567 赞的《米兰设计周「作品排版方法」解析》：

1. **学会梳理**——一板放什么要分主次
2. **建立布局**——每板**一个视觉重心**，重心用色块高亮
3. **美化细节**——统一色块、大小标题分级、字距对比
4. **30 秒电梯法则**——评委 30 秒看不懂就 PASS。讲清、重点、直接
