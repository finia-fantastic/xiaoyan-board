## 第 1 张 · 核心形象

**这张的任务：让人一眼记住她是谁。**

| 板块 | 具体内容 | 现状 |
|---|---|---|
| 项目标题 | 「晓艳先生」+ 一句话概念 | ✅ |
| 副标题 | 方向二 · 名师文化创意表达 · 动漫 IP 形象 | ✅ |
| 人物设定 | 年龄、身份、性格、一句话人设 | ✅ |
| 三视图 | 正面 / 侧面 / 背面，**等大并列** | ✅ |
| 比例标注 | 约 4 头身，标出头身比 | ✅ 三视图上加了标尺，实测 ≈4.4H |
| 特征识别点 | 侧分短发 / 无框眼镜 / 云肩夹克，各配小图 | ✅ 三张裁切小图 + 标签 |
| 色值规范 | 5 色 + HEX | ✅ |
| 主视觉 | 全身立绘或场景图 | ✅ |

## 第 2 张 · 设计推演（最加分的一张）

**这张的任务：证明原创性——你怎么把传统变成结构。**

| 板块 | 具体内容 | 现状 |
|---|---|---|
| 文化依据 | 云肩是什么、承载什么礼、如意云头的形制 | ⚠️ 只有一句话，要展开 |
| 推演三步 | ①传统云肩实物/线稿 → ②提取连续弧线、简化裁片 → ③落到夹克后背 | ✅ |
| **设计草稿** | 手绘感过程图：草图、裁片展开、上身效果，至少 2–3 张 | ⚠️ 补了两张上身稿，但仍是生成稿裁切，最好再补真人手绘 |
| 细节特写 | 后背裁片的织纹、缝线、边缘处理 | ✅ |
| 前后对比 | 正面（当代运动装）vs 背面（云肩轮廓） | ✅ 正面 / 背面 / 后背裁片三张对比，在主图下方 |

**这张的任务：证明这个 IP 能落地、能复制。**
